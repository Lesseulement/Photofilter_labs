## 📖 Обзор проекта
**PhotoCore** — это комплексная веб-система, сочетающая в себе мощь интерактивной 3D-графики на стороне клиента и надежность серверной архитектуры на стороне API. Проект разработан для демонстрации навыков Fullstack-разработки, работы с современными библиотеками визуализации и создания масштабируемых серверных решений.

## 🏗 Архитектура системы
Проект использует **слоистую архитектуру (Layered Architecture)**, что обеспечивает разделение ответственности и легкость поддержки кода:

### Frontend-слой:
- **Three.js**: Используется для высокопроизводительного рендеринга 3D-моделей в формате `.gltf`.
- **Vite**: Современный инструмент сборки, обеспечивающий мгновенный `Hot Module Replacement` (HMR).
- **Компонентный подход**: Интерфейс разбит на независимые модули (MainPage, ProductPage, ProductCardComponent), что позволяет легко управлять состоянием приложения.

### Backend-слой:
- **Express.js**: Легковесный и гибкий фреймворк для Node.js.
- **RESTful API**: Реализован набор стандартных методов для взаимодействия с данными.
- **Service-Layer**: Вся бизнес-логика вынесена в сервисы (`stocksService`), что позволяет отделить работу с файловой системой от обработки запросов.
- **Middleware**: Использование промежуточных обработчиков для логирования, парсинга JSON и обработки ошибок.



## 🚀 Функциональные возможности
1. **Интерактивная 3D-визуализация**:
   - Загрузка и динамическое отображение моделей.
   - Управление камерой через `OrbitControls`.
   - Оптимизация через `requestAnimationFrame` и проверку жизненного цикла компонентов.
2. **Умный поиск**:
   - Фильтрация карточек товаров по их названиям в режиме реального времени.
3. **Пользовательский интерфейс**:
   - Адаптивная верстка с использованием Bootstrap.
   - Горизонтальный скролл для эффективного использования экранного пространства.
   - Делегирование событий для управления сложными DOM-структурами.
