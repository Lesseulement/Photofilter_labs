## 📖 Обзор проекта
**PhotoCore** — это полноценная веб-система, объединяющая интерактивную 3D-графику и серверный REST API. Проект демонстрирует навыки Fullstack-разработки: работу с 3D-моделями через Three.js, взаимодействие с сервером через AJAX и архитектурное построение приложения на Express.js.

## 🏗 Архитектура системы
Проект построен на **слоистой архитектуре**, обеспечивающей разделение логики:
- **Backend (Express.js)**: Состоит из слоев `Routes`, `Controllers` и `Services`, которые изолируют бизнес-логику и работу с JSON-файлом данных.
- **Frontend**: Использует Three.js для рендеринга и модульную структуру (MainPage, ProductPage, Components) для управления состоянием. Взаимодействие с API реализовано через кастомный модуль `Ajax` (на основе XMLHttpRequest).



## 🚀 Функционал и возможности
Проект поддерживает полный цикл работы с данными (CRUD) и интерактивные возможности для пользователя:
1. **3D-визуализация**: Загрузка и управление моделями через `GLTFLoader`.
2. **Поиск**: Фильтрация карточек по названию в реальном времени.
3. **Управление данными**: Кнопки удаления (мгновенное и отложенное через `setTimeout`) на странице товара.
4. **Навигация**: Удобный горизонтальный скролл списка карточек с кастомной полосой прокрутки.
