## 1. HTML-разметка

HTML — это язык разметки, с помощью которого описывается содержимое веб-страницы. В данном проекте использованы основные теги для создания структуры интерфейса:

### Текст и заголовки
```html
<h1>Главный заголовок страницы (PHOTOCORE)</h1>
<span>Малый заголовок надписи "Фоторедактор"</span>
```
Списки и группы
Для логической группировки карточек с инструментами (HDR, Фокус, Дисперсия) используются контейнеры <div>, которые позволяют управлять сеткой элементов через CSS.

## 2. Базовая структура HTML-документа
В файле index.html реализован стандартный каркас:

```html

<!DOCTYPE html> 
<html lang="ru"> 
<head>
  <meta charset="UTF-8">
  <title>PhotoCore - Редактор</title>
  <style>
      /* Глобальные стили проекта */
  </style>
</head>
<body>
    <div id="root"></div> </body>
</html>
```
## 3. Практическая часть: Верстка каталога PHOTOCORE
В рамках работы был создан интерфейс фоторедактора.

HTML-разметка:

Создана навигационная панель с логотипом.

Реализован заголовочный блок с описанием возможностей.

Создан основной контейнер main-page-container для вывода карточек-информеров.

CSS-стилизация:

Использована темная тема оформления (background-color: #0b0e11).

Для расположения элементов применена технология Flexbox.

Карточкам заданы скругления (border-radius), эффекты наведения (hover) и плавные переходы (transition).

## 4. Дополнительное задание
Задание: Выполнить кастомизацию пользовательского интерфейса (UI), применив курсивное начертание шрифта (italic) ко всем элементам управления и текстовым блокам.

Реализация:
Для достижения единообразного стиля во всем приложении была произведена глобальная модификация через универсальный селектор. Это позволило изменить начертание текста даже в тех элементах, где оно задано браузером по умолчанию (кнопки и ссылки).

```CSS

/* Глобальное применение курсивного начертания */
* {
    font-style: italic !important;
}
```
