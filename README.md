## 🏗 Асинхронность и Fetch API

### 1. Введение в Promise
Промис (`Promise`) — это объект, представляющий результат асинхронной операции (операции, которая выполнится в будущем). Он имеет три состояния:
* **Pending**: ожидание, начальное состояние.
* **Fulfilled**: успешное выполнение, результат получен.
* **Rejected**: отклонение, произошла ошибка.

### 2. Async/Await
Использование `async/await` является «синтаксическим сахаром», который позволяет писать асинхронный код, выглядящий как синхронный, заменяя цепочки `.then()` и `.catch()` на блоки `try...catch`.

### 3. Fetch API
Функция `fetch` заменяет `XMLHttpRequest`, предлагая более удобную работу с запросами через промисы.
**Пример реализации метода `get`:**
```javascript
async get(url) {
    try {
        const response = await fetch(url);
        return await response.json();
    } catch (e) {
        console.error('Ошибка:', e);
    }
}
