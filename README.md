## 1. HTML-разметка

HTML - это язык разметки, с помощью которого описывается содержимое веб-страницы: текстовые поля, таблицы, кнопки, заголовки, ссылки, в общем - все, что пользователь видит на странице. Для использования HTML-элементов на странице используются тэги. В основном на каждый элемент в документе приходится по два тэга: открывающий и закрывающий. У тэгов могут быть атрибуты, с помощью которых задается дополнительная информация об html-элементе.

Синтаксис объявления html-элемента выглядит примерно так:
```html
<тэг атрибут="значение_атрибута">Содержимое тэга</тэг>
```

Рассмотрим некоторые html-элементы и их тэги:

### Текст
В html присутствуют 6 тэгов для выделения заголовков:
```html
<h1>Этот текст будет отображен браузером как заголовок первого уровня (крупнейший)</h1>
<h2>А этот - как заголовок второго уровня (поменьше) </h2>
<h6>Самый мелкий заголовок</h6>
```

Текст можно форматировать:
```html
<i> Этот текст будет отображен курсивом </i>
<b> этот будет выделен жирным </b>
<u> а этот будет подчеркнут </u>
```

Текст можно группировать в параграф (абзац):
```html
<p>Это параграф какого-то текста.</p>
<p>Следующий параграф текста</p>
```

### Списки
Ненумерованный список (unordered list UL):
```html
<ul>
  <li> первый элемент списка </li>
  <li> второй элемент списка </li>
  <li> третий элемент списка </li>
</ul>
```

Нумерованный список (ordered list OL):
```html
<ol>
  <li> первый элемент списка </li>
  <li> второй элемент списка </li>
</ol>
```

### Гиперссылки
Для создания ссылки используется парный тэг `<a>`. У него присутствует несколько атрибутов, позволяющих ссылку настроить:
* `href` - адрес ресурса, на который ссылка ссылается
* `target` - в каком фрейме (окне) открывать документ

```html
<a href="[https://google.com](https://google.com)"> Click me! </a>

<a href="[https://google.com](https://google.com)" target="_blank"> Click me! </a>
```

Якорь:
Внутри HTML-страницы с помощью того-же тэга `<a>` можно расставить так называемые “якоря”. Это закладки на странице для перемещения к определенному элементу.
```html
<p>
  <a name="some_paragraph"></a> Lorem Ipsum is simply dummy text...
</p>
<p>
  <a href="#some_paragraph">При нажатии на эту ссылку, пользователь будет перенаправлен к месту установки якоря.</a>
</p>
```

## 2. Базовая структура HTML-документа

Простейший html-документ выглядит следующим образом:
```html
<!DOCTYPE html> <html lang="ru"> <head>
  <meta charset="UTF-8">
  <title>Моя первая страница</title>
</head>

<body>
    <h2>Lorem Ipsum</h2>
</body>

</html>
```

## 3. Практическая часть: Верстка калькулятора (V ATM)

В рамках выполнения работы был создан проект пользовательского интерфейса банковского терминала с калькулятором (V ATM).

**HTML-разметка:**
* В файле `index.html` была создана базовая структура документа.
* Добавлен основной контейнер терминала `atm_main_terminal`.
* Интерфейс разделен на панель вывода данных (экран с историей) и клавиатуру.
* Кнопки сгруппированы с помощью контейнеров `div` по рядам для удобства отображения.

**CSS-стилизация:**
* Подключен файл `terminal.css`.
* Для создания сетки кнопок и позиционирования элементов использована технология Flexbox.
* Реализована темная тема оформления интерфейса.
* Кнопкам заданы скругления углов, добавлены эффекты изменения цвета при наведении (`:hover`) и при клике (`:active`).

## 4. Дополнительное задание

**Задание:** Выполнить кастомизацию пользовательского интерфейса (UI), применив курсивное начертание шрифта (italic) ко всем элементам управления, информационным блокам и текстовым полям вывода данных.

**Реализация:**
Для достижения единообразного визуального стиля во всем веб-приложении была произведена глобальная модификация CSS-правил. Вместо точечного изменения отдельных классов, было принято решение воздействовать на все узлы DOM-дерева.

Глобальная селекция: В основном CSS-файле проекта был использован универсальный селектор *, который позволил переопределить стандартное начертание шрифта даже для элементов с жестко заданными браузерными стилями (таких как кнопки <button> и ссылки <a>).

Приоритезация стилей: Для предотвращения конфликтов со сторонними стилями и гарантии применения курсива к динамически изменяемому тексту (результатам вычислений) был использован модификатор !important.

```CSS

/* Глобальное применение курсивного начертания */
* {
    font-style: italic !important;
}
```
